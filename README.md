# CotizaGo

Aplicação mobile-first para pequenos profissionais e autónomos criarem, enviarem e acompanharem orçamentos.

## Engenharia

Este repositório utiliza uma camada de engenharia orientada por:

- MASTER ORCHESTRATOR
- agentes especializados
- SDDs
- ADRs
- contracts
- audits
- checkpoints
- master checklist

A implementação deve seguir o fluxo definido em `docs/MASTER_ENGINEERING_PROMPT.md`.

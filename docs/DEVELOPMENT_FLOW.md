# Development Flow

```text
Discovery
→ Architecture
→ Database
→ Backend
→ Mobile Foundation
→ Features
→ Offline/Sync
→ PDF/Sharing
→ Public Quote
→ Notifications
→ Billing
→ Security
→ QA
→ Performance
→ DevOps
→ Release
→ Business
```

Cada fase possui um gate. Não avançar enquanto os itens obrigatórios da fase atual não estiverem validados.
